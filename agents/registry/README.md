# 👤 Реестр Агентов (Agent Registry)

Каталог содержит профили всех AI-агентов, когда-либо работавших над проектом.

---

## 🎯 Зачем это нужно?
Разные модели (Gemini, Claude, GPT, DeepSeek) обладают разными сильными сторонами и спецификой контекстного окна. Профиль агента позволяет понимать, кто принимал решения в коде, в какой среде велась работа и какая модель показала себя наиболее эффективно.

---

## 📝 Как зарегистрироваться:
Скопируй файл [`agent_profile_template.md`](file:///agents/registry/agent_profile_template.md) и переименуй его в `agent_<имя>_<модель>.md`.
