# 🚀 Протокол Онбординга Нового Проекта (ONBOARDING_PROTOCOL.md)

Этот протокол запускается, когда каталог `agents/` скопирован в **абсолютно новый или существующий проект**, требующий инициализации «Второго Мозга».

---

## 🎯 Цель онбординга
Превратить универсальный шаблон-заготовку в живой, актуальный центр управления именно этим конкретным проектом без рутинных ручных правок человека.

---

## 📋 Пошаговый алгоритм для AI-агента:

### Шаг 1: Разведка кодовой базы (Codebase Discovery)
1. Просканируй корень проекта:
   - Есть ли уже файлы кода (`package.json`, `requirements.txt`, `Cargo.toml`, `go.mod`, `docker-compose.yml`, `README.md`)?
   - Или папка проекта пока пуста (новый проект с нуля)?
2. Определи:
   - Название проекта (из имени папки, `package.json`, `pyproject.toml` или спроси у пользователя).
   - Основной язык и технологический стек.
   - Главную цель или задачу проекта.

### Шаг 2: Экспресс-инициализация через скрипт
Ты можешь выполнить автоматическую замену плейсхолдеров одной командой:
```bash
python agents/tools/init_project.py --name "ИмяПроекта" --desc "Описание функционала" --stack "Технологии"
```
*Этот скрипт автоматически обновит заголовки в `STATUS.md`, `AGENT_GUIDE.md`, `GLOSSARY.md`, `CODEBASE_MAP.md` и др.*

### Шаг 3: Заполнение карты кодовой базы (`architecture/CODEBASE_MAP.md`)
- Зафиксируй дерево основных каталогов проекта (`src/`, `backend/`, `frontend/`, `tests/` и т.д.).
- Опиши назначение каждого каталога и ключевых файлов.

### Шаг 4: Формирование первой задачи (`tasks/active_task.md`)
- Открой `agents/tasks/active_task.md`.
- Сформулируй задачу `TASK-001 — Инициализация проекта и базового каркаса`.
- Напиши чек-лист конкретных шагов реализации (Шаг 1: окружение, Шаг 2: базовый сервер/UI, Шаг 3: тесты).

### Шаг 5: Регистрация агента (`registry/`)
- Создай файл `agents/registry/agent_<name>_<model>.md` со своими параметрами (модель, IDE, дата).

### Шаг 6: Фиксация первой сессии в `history/`
- Создай `agents/history/session_YYYY-MM-DD_01_init.md` по шаблону `agents/templates/template_session_log.md`.
- Опиши, что проект успешно инициализирован и готов к разработке!

### Шаг 7: Запуск проверки целостности
```bash
python agents/tools/check_integrity.py
```
- Убедись, что все проверки возвращают `[OK]`.
