# 🐛 Баг-репорт: BUG-002 — Ночник не разворачивается на весь экран (position: relative перебивает fixed)

> **Статус:** 🟢 РЕШЕНО (исправлено в v48, 2026-11-01)  
> **Дата обнаружения:** 2026-11-01  
> **Автор / Агент:** ZCode (GLM) — аудит кодовой базы  
> **Компоненты:** `style.css` (блок `.nightmode`), регрессия коммита `6d0d147` (v46)

---

## 🔍 1. Симптом (Что произошло)

При включении «🕯 Ночник» (кнопка в настройках или клавиша `N`) полноэкранный
прикроватный экран с часами **не появляется**. Пользователь не видит никакой
реакции: элемент `#nightMode` получает `hidden = false`, но визуально это
маленький блок высотой ~91px, приклеенный к самому низу документа (в потоке
после футера), а не `position: fixed` оверлей на весь экран.

Инструментальное подтверждение (headless-проверка, вьюпорт 1280×720):

```json
{
  "hidden": false,
  "computedPosition": "relative",
  "rect": { "x": 0, "y": 2315, "w": 1272, "h": 91 },
  "viewport": { "w": 1280, "h": 720 },
  "coversViewport": false
}
```

---

## 🔬 2. Первопричина (Root Cause — ПОЧЕМУ это произошло)

В `style.css` внутри одного правила `.nightmode` объявлены **два взаимоисключающих
`position`** — при переработке стиля в v46 в конец блока случайно попала строка
`position: relative;` (по-видимому, скопированная из старого правила `.nm-time`,
где было `position: relative; z-index: 1`). CSS-каскад: последнее объявление
побеждает, поэтому `position: fixed` (написанный выше в том же правиле) не действует.

```css
/* style.css, блок .nightmode (v46) — БАГ */
.nightmode {
  position: fixed;      /* ← перекрыт */
  inset: 0;
  z-index: 110;
  background: #020305;
  display: grid;
  place-items: center;
  position: relative;   /* ← победитель: элемент в потоке страницы */
}
```

До v46 (коммит `8ea2aed`, v37) правило было корректным: `position: fixed; inset: 0; z-index: 130;`.

---

## 🛠️ 3. Решение (Как исправлено)

Исправлено в v48: строка `position: relative;` удалена из правила `.nightmode`
в `style.css` (фикс одной строки). Дополнительно в v48-блоке возвращён плавный
fade-in экрана (`nmIn`) и элегантные тонкие часы. Проверено вживую:
`#nightMode` при включении — `position: fixed`, `rect 1272×720 @ y=0`,
полноэкранный прикроватный экран с часами, выход по тапу/Esc.

---

## 🛡️ 4. Правило предотвращения (Prevention Rule)

1. В одном CSS-правиле не должно быть двух объявлений одного и того же свойства —
   при код-ревью/аудите проверять дубликаты до каскада, а не после.
2. Регрессия прошла релизный контроль v46: перед bump-версией прогонять
   `agents/testing/QA_CHECKLIST.md` по всем оверлеям (`#overlay`, `#nightMode`,
   `#paletteBackdrop`, `#settingsPanel`, `#sceneryOverlay`), а не только по новым фичам.
