# 🐛 База Знаний по Ошибкам и Багам (Bugs & Fixes)

Каталог предназначен для сбора всех возникавших ошибок, сбоев компиляции, рантайм-исключений и инфраструктурных «граблей».

---

## 🎯 Зачем вести базу багов?
AI-агенты часто наступают на одни и те же грабли: специфичные ошибки операционных систем (Windows vs Linux), тонкости версий библиотек (например, Pydantic v1 vs v2), конфликты сетевых сокетов, кодировки и т.д.  
Фиксация каждого бага гарантирует, что **ни один агент больше не потратит время на повторное решение той же проблемы**.

---

## 📝 Правило фиксации:
1. Как только ты столкнулся с ошибкой и нашел её решение:
2. Скопируй бланк из [`agents/templates/template_bug_report.md`](file:///agents/templates/template_bug_report.md).
3. Создай файл `BUG_XXX_<краткое_название>.md` (например, `BUG_001_port_already_in_use.md`).
4. Обязательно опиши:
   - **Симптом:** Точный traceback или лог.
   - **Первопричина (Root Cause):** ПОЧЕМУ возникло.
   - **Решение:** Как исправлено в коде.
   - **Правило предотвращения:** Четкий запрет или рекомендация.
5. Ознакомься с эталоном в [`BUG_000_example.md`](file:///agents/bugs_and_fixes/BUG_000_example.md).
