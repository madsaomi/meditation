# 🐛 Баг-репорт: BUG-003 — Гонка отложенной очистки бинауральных ритмов: «Выкл» не останавливает звук

> **Статус:** 🟢 РЕШЕНО (исправлено в v48, 2026-11-01)  
> **Дата обнаружения:** 2026-11-01  
> **Автор / Агент:** ZCode (GLM) — аудит кодовой базы  
> **Компоненты:** `app.js` — `setBinaural()` (~строки 2641–2679)

---

## 🔍 1. Симптом (Что произошло)

Если быстро переключить бинауральный режим (например, «🌿 Альфа 10 Гц» → «🧘 Тета 6 Гц»),
то через ~0.3 с глобальная ссылка `binNodes` обнуляется таймером очистки **старого**
режима. После этого нажатие «Выкл» (`setBinaural(null)`) не находит узлов
(`binNodes === null`) и **не может остановить играющие осцилляторы Теты** — гул
в наушниках продолжается до перезагрузки страницы.

Инструментальное подтверждение (вживую в браузере):

```json
{
  "afterSwitch": { "binNodesIsNull": true, "thetaShouldBePlaying": true },
  "afterOff":    { "binNodesIsNull": true, "curBinaural": null }
}
```

После переключения Альфа→Тета и попытки выключить: режим «выключен» по UI,
но `binNodes` пуст и остановить Тету нечем.

---

## 🔬 2. Первопричина (Root Cause — ПОЧЕМУ это произошло)

`setBinaural()` гасит старые узлы через `setTimeout(..., 300)`, внутри которого
выполняется `binNodes = null` — безотносительно того, что за 300 мс ссылка могла
быть **перезаписана новым режимом**. Классическая гонка асинхронной очистки:

```js
if (binNodes) {
  try {
    // ... плавное затухание ...
    setTimeout(() => {
      binNodes.oscL.stop(); binNodes.oscR.stop(); // старые — ок (замкнуты в замыкании)
      binNodes = null;                            // ← БАГ: убивает ссылку на НОВЫЕ узлы
    }, 300);
  } catch {}
}
// ... ниже создаётся новый режим и binNodes = { новые oscL, oscR, g } ...
```

Сценарий: `setBinaural("alpha")` → `setBinaural("theta")` (созданы тета-узлы,
`binNodes` перезаписан) → через 300 мс таймер от альфы обнуляет `binNodes` →
`setBinaural(null)` («Выкл») ничего не очищает, тета-осцилляторы подключены
к `master` с gain 0.18 и играют бесконечно. Попутно: узлы `g`/`panL`/`panR`
не `disconnect()`ятся — утечка аудиографа при каждом таком переключении.

---

## 🛠️ 3. Решение (Как исправлено)

Исправлено в v48 именно по этой схеме: старые узлы захватываются в локальную
переменную `old`, таймер останавливает и `disconnect()`ит только их, а
`binNodes = null` выполняется под guard'ом `if (binNodes === old)`.
Дополнительно `stopAllSounds()` (таймер сна, «Тишина») теперь гасит и
бинауральные волны. Проверено вживую: Альфа→Тета (binNodes жив, указывает на
Тету) → «Выкл» → `binNodes === null`, тишина.

---

## 🛡️ 4. Правило предотвращения (Prevention Rule)

1. Любая отложенная (setTimeout/rAF) очистка состояния обязана проверять,
   что состояние с тех пор не было перезаписано (guard `if (current === captured)`).
2. Аудиоузлы после остановки — всегда `disconnect()` (утечки аудиографа кумулятивны).
3. Пустые `catch {}` вокруг аудиоочистки маскируют именно такие баги (см. ANTI-PATTERN №4):
   минимум — комментарий, что именно глотается и почему это безопасно.
