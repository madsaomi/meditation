# 🧪 Чек-лист Контроля Качества и Регрессионного Тестирования (QA_CHECKLIST.md)

**Проект:** Тихий ум  
Каждый агент перед закрытием задачи или созданием релиза **ОБЯЗАН** выполнить проверку по этому списку.

---

## 📋 Обязательные этапы проверки:

### 1. Статический анализ и целостность кода (Code Quality & Linting)
- [ ] Отсутствуют синтаксические ошибки и неразрешенные импорты.
- [ ] Линтер и тайп-чекер проходят без критических ошибок:
  ```bash
  # Python:
  flake8 . --max-line-length=120
  # или mypy .

  # TypeScript / JavaScript:
  npm run lint
  npm run type-check
  ```
- [ ] В коде нет захардкоженных секретов, паролей или токенов.

---

### 2. Автоматические тесты (Unit & Integration Tests)
- [ ] Запущен полный набор автоматических тестов:
  ```bash
  # Python:
  pytest -v

  # Node.js:
  npm test
  ```
- [ ] Все тесты завершились со статусом `PASSED` (100% прохождение).
- [ ] Покрыты тестами все новые методы и функции, добавленные в текущей задаче.

---

### 3. Работоспособность приложения (Smoke & Runtime Testing)
- [ ] Приложение запускается без падений и ворнингов на чистой базе/окружении.
- [ ] Ключевые эндпоинты (Health check, Auth, базовый API) отвечают со статусом `200 OK`.
- [ ] В консоли сервера нет необработанных исключений (`Unhandled Exception` / `Traceback`).

---

### 4. Пользовательский интерфейс (Frontend / UI / CLI)
- [ ] Интерфейс отображается корректно на десктопных и мобильных разрешениях (Responsive Design).
- [ ] Консоль браузера (DevTools Console) чистая — отсутствуют красные ошибки JS и 404/500 сетевые сбои.
- [ ] Интерактивные элементы (кнопки, формы ввода, модальные окна) реагируют на клики и ввод.

---

### 5. Аудит «Второго Мозга» (Second Brain Integrity)
- [ ] Запущен валидатор целостности:
  ```bash
  python agents/tools/check_integrity.py
  ```
- [ ] Чек-лист в [`agents/tasks/active_task.md`](file:///agents/tasks/active_task.md) актуализирован.
- [ ] Добавлен отчет о сессии в [`agents/history/`](file:///agents/history/).
- [ ] Обновлен статус в [`agents/STATUS.md`](file:///agents/STATUS.md).
