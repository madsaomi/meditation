# 📖 Глоссарий предметной области (GLOSSARY.md)

Словарь терминов, аббревиатур и понятий проекта **Тихий ум**.  
Служит для предотвращения смысловых разночтений, галлюцинаций и путаницы между разными AI-агентами и разработчиками.

> [!TIP]
> Каждый входящий агент, встречая новые предметные термины, бизнес-понятия или специфичные сокращения, **ОБЯЗАН** заносить их в эту таблицу с кратким и однозначным пояснением.

---

| Термин / Сокращение | Определение / Значение в рамках проекта |
|---|---|
| **Second Brain** | Система каталога `agents/`, хранящая всю долговременную память, архитектуру, решения и правила проекта. |
| **ADR** | *Architecture Decision Record* — документ, фиксирующий ключевое архитектурное решение, его контекст и последствия. |
| **MVP** | *Minimum Viable Product* — минимально жизнеспособный продукт, обладающий достаточным функционалом для первого использования. |
| **CI/CD** | *Continuous Integration / Continuous Deployment* — автоматизация сборки, тестирования и выкатки кода. |
| **Root Cause** | Первопричина дефекта или бага, выявляемая при заполнении отчета в `agents/bugs_and_fixes/`. |

> [!NOTE]
> Добавляйте новые термины предметной области проекта в таблицу выше по мере их появления.
