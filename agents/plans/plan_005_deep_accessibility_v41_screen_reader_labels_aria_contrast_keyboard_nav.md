## 1. 🎯 Цель и контекст

- **Проблема / Задача:** Сайт работает преимущественно визуально — цветовые индикаторы, иконки, hover‑эффекты.   - Контрастность цветовых переменных `--accent` / `--text` соответствует WCAG AA на светлых и темных темах.
  - Все интерактивные элементы достижимы Tab и имеют понятные имена.
  - Нет регрессов в уже работающей вёрстке.

### Этап 2: Реализация базовой логики
- [ ] Шаг 2.1: В `style.css` добавить блок `.high-contrast { --accent: #...; ... }` и медиа‑правило `[data-contrast="high"]` для принудительного_high_contrast_режима (опционально).
- [ ] Шаг 2.2: Проверить существующие правила контрастности через онлайн‑сервис (или эмпирически): 
  - `--accent: #6f9e8f` на `--text: #263238` — OK (AA).
  - `--accent: #c08a5a` на `--text: #263238` — OK.
  - `--accent: #6f9e8f` на `--text: #dfe4ec` (ночной фон) — проверить, возможно, нужно темнее `--text` или светлее `--accent`.
- [ ] Шаг 2.3: При необходимости скорректировать переменные `--accent` или `--text` в темах, чтобы оба сочетения соответствовали WCAG AA.
- [ ] Шаг 2.4: Добавить `.chip` и `.sound` элементы `aria-label` через `app.js` при создании (они уже имеют текстовое содержимое, но нужно убедиться, что скринридеры прочитают смысл).
- [ ] Шаг 2.5: Добавить `role="img"` и `aria-label` для SVG‑лотоса: `<svg aria-label="Лотос практики: каждый цикл дыхания раскрывает лепесток; при 8 циклах цветок полный">`.
- [ ] Шаг 2.5: Добавить `aria-label` для чипов дрона (`aria-label="Тон-дрон: 111 Гц, медитативный тон с обертонами"`) и чипов колокола (`aria-label="Оттенок колокола: Храм, низкий храмовый тон"`).
- [ ] Шаг 2.6: Убедиться, что порядок табуляции (`tabindex`) логичен: шапка → основной контент → секции (дыхание, техники, таймер, звуки) → настройки.

## 4. 🛡️ Риски, сайд‑эффекты и план отката (Rollback Strategy)
- **Потенциальные риски:** 
  - Изменение цветов может сделать визуал менее «ярким» для sighted пользователей — mitigated флагом `--contrast-check` и gradual change.
  - Добавление ARIA‑атрибутов может сломать чтение, если формат неверный — mitigated использованием проверенных паттернов и тестированием скринридерами.
- **План отката в случае сбоя:** `git checkout main` к предыдущему коммиту (v40). Изменения но additive, отключение ARIA‑меток просто удалением атрибутов из HTML.
