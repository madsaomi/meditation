# 🚀 Отчеты о приемке и демонстрации (Walkthroughs)

> [!TIP]
> **Приемка фичи (Acceptance Gate):**  
> После завершения реализации любого плана из [`agents/plans/`](file:///agents/plans/) агент формирует подробный отчет о приемке по шаблону [`agents/templates/template_walkthrough.md`](file:///agents/templates/template_walkthrough.md).

---

## 🎯 Назначение папки
В эту папку (`agents/walkthroughs/`) сохраняются отчеты о завершении работ, результаты ручного и автоматического тестирования, демонстрации UI и релизные отчеты.

Формат именования файлов:  
`walkthrough_<номер>_<краткое_название>.md` (например: `walkthrough_001_auth_system.md`, `walkthrough_002_cart_checkout.md`).

---

## 📋 Структура Walkthrough:
1. **Резюме изменений:** что конкретно было создано и модифицировано.
2. **Результаты автоматических тестов:** логи прохождения pytest / npm test со 100% успехом.
3. **Ручная проверка и сценарии:** пошаговое подтверждение работы ключевых пользовательских сценариев.
4. **Критерии готовности (DoD):** отметка всех пунктов проверки перед сдачей пользователю.
