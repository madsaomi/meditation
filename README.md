# 🧘 Тихий ум — сайт для медитации

Спокойный одностраничный сайт: дыхательные практики, медитативный таймер,
тихие звуки и мудрые мысли. **Всё содержимое приходит с внешних API** —
на сервере ничего хранить не нужно.

## Запуск

Просто откройте `index.html` двойным щелчком — сайт работает из файла.
Для лучшего результата можно запустить любой локальный сервер, например:

```powershell
python -m http.server 8080
# затем откройте http://localhost:8080
```

## Что берётся с API

| Что                | API                                   | Ключ нужен? |
|--------------------|----------------------------------------|-------------|
| Цитаты на русском  | [ru.wikiquote.org](https://ru.wikiquote.org) (MediaWiki API) | нет |
| Советы дня         | [Advice Slip](https://api.adviceslip.com) | нет |
| Коллекция цитат    | [DummyJSON Quotes](https://dummyjson.com) | нет |
| Автоперевод EN→RU  | [MyMemory](https://mymemory.translated.net) | нет |
| Фоновая музыка     | SoundHelix (15 треков, случайный выбор) | нет |

Мысль дня обновляется автоматически каждые 5 минут: источники чередуются,
переводы кешируются локально, при недоступности API включается офлайн-подборка.
Кнопка «🎧 Послушать» озвучивает мысль голосом.

Все адреса собраны в одном месте — **config.js**. Хотите свой бэкенд?
Замените URL в `config.js` на свой эндпоинт и пусть он возвращает JSON
вида `{ "text": "...", "author": "..." }` — остальной код менять не нужно.

Если все API недоступны (нет интернета), сайт вежливо переключается на
офлайн-подборку фраз — ничего не ломается.

## Локальные функции (не требуют интернета)

- **Дыхание** — пять ритмов: 4·7·8, «квадрат», 5·5, 4·6 (антистресс), 7·8 (для засыпания); выбор запоминается; дышащий круг с дугой-прогрессом фазы и отсчётом секунд; фаза дублируется в заголовок вкладки. Системная настройка «меньше движения» гасит декор, оставляя функциональные анимации практики.
- **Живой герой** — секция дыхания не замирает: idle-круг дышит в ритме выбранного паттерна, точка-орбита медленно обегает внешнее кольцо, внутреннее кольцо мягко «дышит» вместе с практикой, за героем плывут два ауры-орба, по приветствию бежит световой акцент, кнопка «Начать» пульсирует в том же ритме — всё привязано к одной переменной `--breath-cycle` и чистому CSS.
- **Живая шапка** — плавающая капсула: навигация в стеклянном лотке с «бегунком» текущего раздела (обновляется при прокрутке), у бренда дышащая точка в ритме практики, иконочные кнопки круглые, у голоса состояние читается по эмодзи 🔊/🔇.
- **Голос** — встроенный синтезатор речи: выбирает лучший русский голос, скорость и высота чуть меняются, фразы не повторяются слово в слово (кнопка 🔇 в шапке, работает офлайн).
- **Таймер** — пресеты 5–30 минут и своя длительность (1–180 минут), прогресс-кольцо, мягкий колокольчик и голос в конце (Web Audio), обратный отсчёт в заголовке вкладки.
- **Звуки** — 12 источников: дождь, ручей, океан, ветер, костер, гроза, сверчки, птицы, колокол (удары каждые 9–18 сек), колокольчики, белый шум синтезируются в браузере; музыка — 15 треков SoundHelix, каждый включается случайно. У каждой плитки — подсказка при наведении. Пространственный стереозвук: у каждого источника своё место в панораме (дождь чуть слева, птицы справа, сверчки — правее) с лёгкой случайностью при каждом запуске; чип «🎧 Пространство» выключает панораму, возвращая звуки в центр.
- **Миксы** — готовые сочетания в один клик: «🌧 Дождь с грозой», «🔥 У камина», «🌊 Океан и ветер», «🌲 Ручей и птицы», «💤 Сон», «⏹ Тишина» и «🎲 Случайный» (подбирает микс по времени суток — ночью мягче и тише). Микс выключает лишнее (включая музыку), включает свои источники и подстраивает громкость; ручная правка плиток сразу снимает активность микса. Последний применённый микс запоминается — чип «🔁 Повторить» вернёт его в один клик.
- **Тихий фон сеанса** — если на старте таймера тишина, автоматически включается едва слышный фон на громкости 22. Звук выбирается в настройке таймера: «Авто» (по времени суток — ночью океан, днём дождь), дождь, океан, ручей или вовсе «Нет». К финалу фон плавно уходит, оставляя колокол и голос; чужие звуки практика не трогает.
- **Дыхание вместе с таймером** — чип «🌬 Дыхание вместе с таймером»: пока идёт сеанс, мягкий дыхательный цикл ведёт вас автоматически; пауза, сброс и финиш останавливают его вместе с таймером.
- **Дыхательные отклики** — чип «🌬 Звук и вибро при смене фаз»: едва слышный поток воздуха (синтез Web Audio) повторяет ритм — вдох наполняет, выдох стихает, задержка замирает; на смене фаз — короткий вибро-такт (мобильные), финал таймера — вибро-урон.
- **Быстрые техники** — семь практик от 20 секунд до 5 минут: «Пауза на минуту», «Один цикл 4·7·8», «Заземление 5–4–3–2–1», «Сканирование тела», «Полный цикл 4·7·8», «Момент благодарности», «Осознанная прогулка» и «🎲 Случайная техника». Каждый шаг ведётся голосом; оверлей закрывается по Esc, кнопке или клику по фону.
- **Сценарии** — ритуал в один клик: «🌙 Сон» (ночная тема, океан, дыхание 4·7·8, таймер сна 30), «🔥 Уют» (костёр, тёмная тема, 15 минут), «⚡ Фокус» (белый шум, чистый экран, 25 минут), «🌅 Утро» (ручей и птицы, ритм 5·5, 10 минут). Во время идущего сеанса сценарий вежливо попросит остановиться. Кнопка «💾 Своя сцена» запоминает текущую атмосферу — звуки, громкость, таймер, ритм, тему, голос — под своим именем (до шести; клик включает, ПКМ по чипу — удалить).
- **Пульт команд ⌘K / Ctrl+K** — всплывающий поиск по всему сайту: звуки, миксы, сценарии, свои сцены, ритмы дыхания, техники, длительности таймера, темы, режимы, якорь, переходы по секциям. Печатаете частицу названия — ↑↓ выбирает, Enter выполняет, Esc закрывает; кнопка 🔍 в шапке открывает то же самое. Пульт понимает числа: «таймер 45» и «громкость 30» применяются сразу; недавние команды всплывают сверху при пустом запросе.
- **Панель настроек ⚙** — все переключатели в одном месте: тема (Авто/Ночь/Глубокая), голос, тихий фон сеанса, дыхание с таймером, отклики фаз; состояние синхронизировано с чипами в секциях. Закрывается по Esc или клику мимо.
- **Тема под время суток** — утро/день/вечер/ночь меняют палитру и приветствие; кнопка в шапке циклически: авто → «Ночь» → «Глубокая ночь» (OLED, почти чёрный фон) → авто.
- **Сезонные акценты** — палитра автоматически подмешивает характер сезона: зимой прохладнее, летом теплее, осенью золотее — по дате, без единой кнопки; строка сезона видна в панели настроек.
- **Северное сияние ночью** — в ночной теме фон оживает: очень медленное (≈42 с) едва заметное свечение-полярное сияние, чистый CSS без частиц; днём слой полностью прозрачен.
- **Ночник 🕯** — прикроватный экран: крупное спокойное время и медленно дышащий свет, длина «вдоха» берётся из выбранного ритма дыхания. Выход — тап или Esc, вход — клавиша N, кнопка в настройках или команда «Режим: Ночник» в пульте.
- **Спящий экран** — ползунок затемнения в настройках (0–70%): лёжа в постели экран можно убавить, не трогая системные настройки; состояние запоминается.
- **Фокус-режим** — кнопка «⛶ Фокус» прячет весь интерфейс, оставляя только дышащий круг; Esc — выход.
- **Таймер сна** — «💤 Сон»: звуки мягко выключатся сами через 15/30/60 минут.
- **Колокол-якорь** — чип «🔔 Якорь» (5/10/15/20 минут): во время сеанса мягкий одиночный звонок тише финального напоминает вернуться к дыханию, кольцо таймера отвечает едва заметной вспышкой; пауза и сброс учитываются автоматически, выбор запоминается.
- **Память настроек** — громкость, выбранный ритм дыхания, последняя длительность таймера (включая «Свою»), якорь, затемнение и свои сцены сохраняются в localStorage и восстанавливаются при следующем визите: тот, кто всегда практикует 20 минут, просто жмёт «Старт».
- **Серия практик** — число дней подряд с практикой — огонёк 🔥 в шапке.
- **Горячие клавиши** — пробел: старт/стоп дыхания; Ctrl+K / ⌘K: пульт команд; N: ночник; Esc: выход из фокуса, техник, ночника и пульта; 1–9: быстрое переключение звуков.
- **Мысль дня** — чередует 3 API, обновляется каждые 5 минут, переводы кешируются локально; во время загрузки — скелетон- shimmer; кнопка ⧉ копирует цитату с автором в буфер (с запасным путём на file://).
- **Установка на телефон** — PWA-манифест с SVG-иконкой: при открытии с сервера сайт ставится на домашний экран и запускается без адресной строки.

## Структура

```
index.html   — разметка: плавающая шапка-капсула с живой навигацией и четыре секции: Мысль, Техники, Таймер, Звуки
style.css    — редизайн: матовое стекло, темы под время суток + OLED-ночь, адаптив от 390px
config.js    — адреса всех внешних API
app.js       — вся логика: дыхание, таймер, звуки и миксы, стереопанорама, сценарии (встроенные и свои), пульт команд, мысли, статистика, панель настроек
manifest.webmanifest, icon.svg — PWA-манифест и иконка для установки
```
