# 🧘 Тихий ум — сайт для медитации

Спокойный одностраничный сайт: дыхательные практики, медитативный таймер,
интерактивный Сад Дзен, стереофонические бинауральные ритмы, полноэкранные живые сцены,
тихие звуки природы и мудрые мысли. **Всё содержимое приходит с внешних API** или генерируется процедурно —
на сервере ничего хранить не нужно.

## Запуск

Просто откройте `index.html` двойным щелчком — сайт работает из файла.
Для лучшего результата можно запустить любой локальный сервер, например:

```powershell
python -m http.server 8080
# затем откройте http://localhost:8080
```

## Что берётся с API

| Что                | API                                   | Ключ нужен? |
|--------------------|----------------------------------------|-------------|
| Цитаты на русском  | [ru.wikiquote.org](https://ru.wikiquote.org) (MediaWiki API) | нет |
| Советы дня         | [Advice Slip](https://api.adviceslip.com) | нет |
| Коллекция цитат    | [DummyJSON Quotes](https://dummyjson.com) | нет |
| Автоперевод EN→RU  | [MyMemory](https://mymemory.translated.net) | нет |
| Фоновая музыка     | SoundHelix (15 треков, случайный выбор) | нет |

Мысль дня обновляется автоматически каждые 5 минут: источники чередуются,
переводы кешируются локально, при недоступности API включается офлайн-подборка.
Доступен рубрикатор мудрости: Стоицизм, Дзен & Дао, Осознанность.
Кнопка «🎧 Послушать» озвучивает мысль голосом.

Все адреса собраны в одном месте — **config.js**. Хотите свой бэкенд?
Замените URL в `config.js` на свой эндпоинт и пусть он возвращает JSON
вида `{ "text": "...", "author": "..." }` — остальной код менять не нужно.

Если все API недоступны (нет интернета), сайт вежливо переключается на
офлайн-подборку фраз — ничего не ломается.

## Локальные функции (не требуют интернета)

- **Главная студия (Zen Studio Bento)** — удобный переключатель между тремя сценами: `[🌬 Дыхание]`, `[⏱ Таймер]` и `[🪨 Сад Дзен]`.
- **Интерактивный Сад Дзен (Canvas 2D)** — тактильный холст с граблями, камнями и кругами на воде:
  - *🏖 Песок:* рисование мягких борозд с объёмной тенью и процедурным шелестом песка в реальном времени.
  - *💧 Вода:* расходящиеся круги на воде от кликов с чистым звуком капли.
  - *🪨 Камни:* расстановка гладких речных камней с градиентными концентрическими дзен-кругами (или двойной клик).
  - *🧹 Разгладить:* плавное очищение холста.
- **Бинауральные ритмы для мозга (Web Audio API)** — чистый стереофонический синтез для наушников (L/R panner):
  - 🌿 *Альфа (10 Гц)* — расслабление и творчество.
  - 🧘 *Тета (6 Гц)* — глубокая медитация и полудрёма.
  - 🌙 *Дельта (2 Гц)* — глубокий сон и регенерация.
  - ⚡ *Гамма (40 Гц)* — предельная концентрация и ясность ума.
- **Полноэкранные живые сцены (`🌌 Сцены`)** — 60 FPS процедурный рендер для созерцания:
  - 🔥 *У костра:* физика искр, тлеющих углей и динамического пламени.
  - 🌊 *Океан под луной:* мягкие гармонические волны ночного прибоя с лунным ореолом.
  - ✨ *Звёздное небо:* мерцающие созвездия с параллаксом глубины.
- **Дыхание** — практики 4·7·8, «квадрат», 5·5, 4·6 (антистресс), 7·8 (сон), соматический «Вздох 3·1·6»; сфера Apple Breathe + адаптивный чек-ин самочувствия.
- **Таймер** — пресеты 5–30 минут и своя длительность (1–180 минут), прогресс-кольцо, мягкий колокольчик и голос в конце (Web Audio), обратный отсчёт в заголовке вкладки.
- **Звуки природы (16 источников)** — дождь, ручей, океан, ветер, костер, гроза, сверчки, птицы, мурлыканье кошки, капли по деревянной крыше, перестук ночного поезда, тибетская чаша, колокольчики, белый шум, дрон/тон, музыка SoundHelix.
- **Готовые миксы** — «🌧 Дождь с грозой», «🔥 У камина», «🛖 Уютный чердак», «🛣 Ночная дорога», «🌊 Океан и ветер», «🌲 Ручей и птицы», «🍃 Шелест леса», «🕉 Обитель покоя», «💤 Сон», «⏹ Тишина» и «🎲 Случайный».
- **Быстрые техники** — 14 соматических практик: «Пауза на минуту», «Один цикл 4·7·8», «Заземление 5–4–3–2–1», «Физиологический вздох», «Сканирование тела», «Момент благодарности», «Осознанная прогулка» и др.
- **Пульт команд ⌘K / Ctrl+K** — всплывающий поиск по всему сайту: звуки, миксы, сцены, ритмы, техники, таймер, темы.
- **Темы оформления (Luminous Zen)** — светлый перламутровый день, обсидиановый космос ночью, глубокая OLED-ночь, сезонные акценты.
- **Ночник 🕯** — прикроватный экран с большими часами и медленным дыханием света.
- **Установка на телефон** — PWA-манифест с иконкой для добавления на экран смартфона.

## Структура

```
index.html   — разметка: студия Zen Bento, Сад Дзен, оверлей сцен 🌌, шапка, Bento-модули
style.css    — весь дизайн Luminous Zen, Bento-сетка, стили холстов сада и сцен v1..v46
app.js       — логика: дыхание, таймер, Сад Дзен, 16 звуков, бинауральные ритмы, сцены, пульт ⌘K
config.js    — адреса всех внешних API
manifest.webmanifest, icon.svg — PWA-манифест и иконка для установки
agents/      — экосистема «Второго Мозга» (планы, задачи, история, регламенты)
```
